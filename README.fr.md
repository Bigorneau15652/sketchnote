# Sketchnote

Plugin Obsidian pour dessiner des sketchnotes : une page unique qui mêle dessins faits à la main et texte manuscrit, organisée selon l'une des sept structures (linéaire, radiale, verticale, chemin, modulaire, gratte-ciel, pop-corn).

État : version 0.47.0. Une page de sketchnote avec sept structures, des dessins faits directement sur la page, zone par zone, avec des outils à main levée. Les lignes et flèches comme sur Excalidraw, le texte, une bibliothèque de dessins et les exports sont construits version après version (voir CHANGELOG.md).

## Installer avec BRAT

1. Dans Obsidian, ouvrez Paramètres, Modules communautaires, installez et activez BRAT.
2. Ouvrez les paramètres de BRAT, cliquez sur Add beta plugin, collez `Bigorneau15652/sketchnote`, puis cliquez sur Add plugin.
3. Activez Sketchnote dans les modules communautaires.
