# Sketchnote

Obsidian plugin to draw sketchnotes: one page that mixes hand-drawn pictures and handwritten text, organised by one of seven structures (linear, radial, vertical, path, modular, skyscraper, popcorn).

Status: version 0.10.1. A sketchnote page with seven structures, graphic elements that open as drawing notes with hand drawn tools. Lines and arrows like Excalidraw, text, a library of drawings and the exports are being built version by version (see CHANGELOG.md).

## Install with BRAT

1. In Obsidian, open Settings, Community plugins, install and enable BRAT.
2. Open the settings of BRAT, click Add beta plugin, paste `Bigorneau15652/sketchnote`, then click Add plugin.
3. Enable Sketchnote in Community plugins.
